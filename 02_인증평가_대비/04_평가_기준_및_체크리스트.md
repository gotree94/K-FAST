# 평가 기준 및 체크리스트 (3개 평가 항목 요약)

> **파일 경로** : `02_인증평가_대비/04_평가_기준_및_체크리스트.md`
> **용도** : 인증 평가의 3개 항목(서술시험·강의안·강의영상)이 어떤 기준으로 평가될지 예상하고,
> 스스로 점검하기 위한 체크리스트.

---

## 1. 평가 항목 개요 (예상 배점 구조)

| 평가 항목 | 평가 내용 | 예상 비중(안) |
|-----------|-----------|---------------|
| 서술시험 | NPU, RNGD, AI 추론 및 교육내용 이해도 | 40% |
| 강의안 평가 | 강의 구성 및 실습 설계 | 30% |
| 강의영상 평가 (5분 내외) | 강의 전달력 및 실습 진행능력 | 30% |

> 실제 배점은 주관처 공지 기준으로 확정하세요. 아래는 "무엇을 보는가"에 대한 해석 가이드입니다.

---

## 2. 서술시험 체크리스트

### 지식 (정확성)
- [ ] 학습(Training)/추론(Inference) 차이를 정확히 서술
- [ ] NPU 아키텍처 요소(PE·SRAM·HBM·NoC·PCIe) 역할 설명 가능
- [ ] 컴퓨트 바운드/메모리 바운드 판별과 대응 설명 가능
- [ ] 양자화 효과와 주의점 설명 가능
- [ ] RNGD 핵심 사양(정밀도별 성능, 48GB/1.5TB/s, SRAM 256MB, TDP 150W, PCIe Gen5) 암기
- [ ] TCP 아키텍처와 PE 8개 구조 설명 가능
- [ ] SW 스택 계층별 역할(드라이버→컴파일러→런타임→furiosa-llm) 구분
- [ ] ENF와 FXB 차이, FXB 지문/빌드·서빙 시점 규칙 설명
- [ ] TTFT/TPOT/토큰/s/p95·p99 정의 및 트레이드오프 서술
- [ ] furiosa-smi/perf/bench 용도 구분
- [ ] 실습 절차(환경 점검→추론→서버→모니터링) 및 오류 대응 서술

### 표현 (논리성·완성도)
- [ ] "정의→원리→예시(수치)→시사점" 순서로 서술
- [ ] 수치는 정확히, 모르면 논리적으로만 서술
- [ ] 관계형 질문(트레이드오프 등)에서 양측 모두 서술
- [ ] 답안이 채점 포인트 키워드를 최소 80% 포함

---

## 3. 강의안 평가 체크리스트

### 구성 (강의 구성)
- [ ] 학습 목표가 행동 동사+산출물로 구체화
- [ ] 도입→이론→실습→정리 흐름과 시간표 명시
- [ ] 이론/실습 비율이 목표에 맞는가 (실습 중심이면 50% 이상)
- [ ] 시간표 합계가 정확하고 버퍼(10~20%) 포함

### 실습 설계
- [ ] 실습이 학습 목표와 1:1 대응
- [ ] 실습마다 명령어·예상 결과·성공 판정 기준 명시
- [ ] 오류 시나리오와 대안 명시
- [ ] 수준별(초/중/상) 과제 제시
- [ ] 산출물(실습일지·스크린샷) 정의

### 운영
- [ ] 사전 준비물(드라이버·HF 토큰·장비·계정) 명시
- [ ] 리스크 표와 대안 제시
- [ ] 평가·피드백(체크리스트·설문) 계획 명시

---

## 4. 강의영상 체크리스트 (5분 내외)

### 시간·구성
- [ ] 5분 ±30초 내 완결
- [ ] 오프닝 15초 내 목표·이유 제시
- [ ] 시연이 전체의 절반 이상
- [ ] 요약 3줄 + 다음 내용 안내로 마무리

### 전달력
- [ ] 자연스러운 속도와 호흡, 군더더기 없음
- [ ] 용어를 한 문장으로 풀이
- [ ] 시선·화면 처리가 안정적
- [ ] "~입니다" 일관 어미 사용

### 실습 진행능력
- [ ] 시연 전 예상 결과 언급
- [ ] 단계를 소리내어 안내
- [ ] 실행 결과를 해석하며 넘어감
- [ ] 오류 발생 시 해결하고 설명

---

## 5. 최종 점검 (제출 전)

- [ ] 3개 산출물(서술 답안지·강의안 1부·영상 1개)이 모두 준비
- [ ] 강의안·영상이 동일 주제(모듈 3 추천)로 일관성 유지
- [ ] 서술 답안은 손글씨 연습 포함 2회 이상 작성
- [ ] 강의안은 제3자 검토 1회
- [ ] 영상은 편집 후 시간 확인 및 재시청
- [ ] 평가 항목별 체크리스트에 모두 체크
