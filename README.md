## 3. 문서 활용 방법

1. **사전 학습** : `01_교육내용_준비자료/` 의 5개 모듈을 순서대로 학습하면
   온보딩 교육에서 가르쳐야 할 내용 전체를 파악할 수 있습니다.
2. **서술시험 대비** : `01_서술시험_예상문제_및_모범답안.md` 의 문제를 스스로 풀어보고
   모범답안의 키워드가 빠짐없이 들어갔는지 확인합니다.
3. **강의안 작성 연습** : `02_강의안_작성_가이드.md` 의 템플릿을 이용해
   1개 모듈(예: 3번 모듈 "LLM 추론 실행")의 강의안을 미리 작성해 봅니다.
4. **영상 촬영 연습** : `03_강의영상_제작_가이드.md` 를 참고해 5분 내외의
   시범 강의(이론 2분 + 실습 시연 3분)를 촬영해 스스로 점검합니다.

## 4. 사전 준비 체크리스트

- [ ] 5개 모듈의 학습 목표와 핵심 개념을 암기 수준이 아니라 "설명 가능" 수준으로 이해
- [ ] RNGD 사양(정밀도별 성능, 메모리, 대역폭, TDP 등) 주요 수치 암기
- [ ] 소프트웨어 스택의 각 구성 요소(드라이버·컴파일러·런타임·furiosa-llm·furiosa-smi) 역할 구분 설명 가능
- [ ] LLM 추론 실습 코드(furiosa-llm Python API, OpenAI 호환 서버) 한 번 이상 직접 실행
- [ ] furiosa-smi status 출력값(코어 활용률, 전력, 온도) 읽는 법 숙지
- [ ] TTFT, TPOT, 토큰/s, 지연시간 백분위(p95/p99), NPU 활용률 등 성능 지표 정의 설명 가능
- [ ] 파일럿 교육과정을 2~3일 단위로 편성한 커리큘럼 초안 1벌 준비
- [ ] 서술시험 예상문제 3세트 이상 직접 작성(시간 재서 연습)
- [ ] 5분 강의영상 스크립트 작성 및 녹화 연습 1회 이상
